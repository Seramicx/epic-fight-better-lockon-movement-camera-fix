## 2.0.0

- **Breaking:** [Shoulder Surfing Reloaded](https://www.curseforge.com/minecraft/mc-mods/shouldersurfing) is now required. The over-the-shoulder camera, hide-player, look-down centering, and shoulder-aware pick raytrace are removed. SSR provides them.
- The `O` shoulder cycle (`right → left → overhead`) is preserved, layered on top of SSR via its plugin API.
- Fixed unpredictable EpicFight dodge / Bosses' Rise roll direction when SSR is decoupled.
- Valkyrien Skies + SSR camera offset is **not** supported in this release. Deferred until SSR has VS support or a follow-up.

**Minecraft:** 1.20.1 Forge. **Requires:** Epic Fight + Better Lockon + Shoulder Surfing Reloaded (4.22.x).
